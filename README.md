# When Models Meet Data

Deck 08 of the [Mathematics for Machine Learning &mdash; Companion Series](https://github.com/BrendanJamesLynskey/MML_Hub).

**Live presentation:** https://brendanjameslynskey.github.io/MML_08_When_Models_Meet_Data/

Data &amp; features, empirical risk minimisation, the bias-variance trade-off,
regularisation, cross-validation, MLE vs MAP, directed graphical models.
Interactive polynomial-fitting demo with live bias/variance and learning-curve
readouts.

## What's inside

- Three components: data, model, predictor
- Empirical risk minimisation (ERM) and the law of large numbers it relies on
- The bias-variance decomposition with an interactive polynomial fit
- Regularisation: from "be smooth" to a prior on parameters
- Cross-validation: hold-out, $k$-fold, leave-one-out
- Maximum likelihood vs maximum a posteriori
- Probabilistic modelling and the generative / discriminative split
- Directed graphical models (Bayesian networks)
- The information-theoretic view: KL divergence and the deviance
